# منصة البرمجة والذكاء الاصطناعي التفاعلية

## كيفية التشغيل والتجربة:

### 1. التشغيل المباشر في المتصفح (بدون سيرفر):
- فقط قم بفك الضغط عن هذا المجلد.
- انقر مرتين على ملف `index.html`.
- ستعمل المنصة مباشرة بكافة مميزاتها (الشرح، الاختبارات، التبديل العشوائي للخيارات).

### 2. الرفع على GitHub Pages:
- ارفع جميع ملفات المجلد إلى مستودع GitHub.
- من إعدادات المستودع (Settings -> Pages)، اختر فرع `main` ثم `Save`.

### 3. التشغيل والنشر على ASP.NET Core / IIS:
- افتح المشروع في Visual Studio أو شغل الأمر `dotnet run`.
- للنشر على IIS: انقل المجلد إلى سيرفر IIS واضبط الـ Application Pool على `No Managed Code`.
